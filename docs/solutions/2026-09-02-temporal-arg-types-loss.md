# Temporal молча выбрасывал типы аргументов активностей

## Ситуация

Диалог уточнений был сломан: активность получила `issue` словарём и упала
`AttributeError: 'dict' object has no attribute 'repo'`, три попытки, задача встала.
Ошибка выглядела как дефект в теле активности — искали её не там.

## Причина

SDK: `arg_types` считается по всем параметрам, включая имеющие значения по умолчанию.
Если вызывающий передал меньше аргументов, типы отбрасываются целиком — и сырой JSON
уезжает во все параметры сразу, а не только в пропущенный. Попутно найдено второе: четыре
места звали активность «показать реакцию» с двумя аргументами, когда хотели написать
человеку сообщение, — неверная арность, неверные типы, неверный смысл.

## Решение

Девять мест вызова исправлены; тест закрепляет соответствие сигнатур и типов;
запрещено полагаться на значения по умолчанию в аргументах активностей, пересекающих
границу воркфлоу/активность.

## Как проверить

`test_activity_arg_types`; диалог уточнений отвечает в живом прогоне.

## Уроки

Temporal прощает рассинхрон сигнатур молча — словари вместо объектов; самый тихий
и самый дорогой класс ошибок на границе воркфлоу/активность, стык закрепляют тестом.
