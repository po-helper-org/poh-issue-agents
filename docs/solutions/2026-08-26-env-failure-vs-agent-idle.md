# Отказ окружения не выглядит бездействием агента

## Ситуация

Задача дошла до разработки, агент запустился и через 82 секунды прогон объявлен
провалившимся: «агент не изменил ни одного файла — открывать нечего». Задача ушла
человеку с метками ошибки. На деле в каталоге разговора раннера — пусто: агент не сделал
ни одного хода, умер на инициализации MCP: прокси индекса лежал.

## Причина

Проверка писала конфигурацию MCP по флагу «включено», а не по живости прокси; пустой
прогон агента трактовался как его вина.

## Решение

Проба живости перед записью конфигурации (проба уже была в модуле — на пути разработки
её просто не звали): не отвечает — конфигурация не пишется, предупреждение в лог, агент
работает без индекса. Это не новое поведение, а выполнение обещанного документацией.
Пустой прогон перестал читаться однозначно: различаются «не сделал» и «не смог начать».

## Как проверить

Тесты пустого прогона; при лежащем прокси разработка проходит без индекса и не обвиняет
агента.

## Уроки

Перед дорогим запуском — проба живости зависимостей; «агент ничего не сделал» и «среда
не дала начать» — разные диагнозы с разными адресатами.
