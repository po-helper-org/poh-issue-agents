# Контекст Issue доезжал до агента разработки частично

## Ситуация

Агент разработки получал постановку без плана декомпозиции, обсуждения и двух артефактов
аналитики — терялось по дороге.

## Причина

Сборка постановки не включала все источники контекста; потери не были видимы никому:
прогон отрабатывал, качество постановки никто не мерил.

## Решение

Постановка агента собирает полный контекст: план декомпозиции, обсуждение Issue,
артефакты аналитики. Дальнейшая эволюция той же боли — PR 244/247/248 (заголовки секций,
приоритет усечения) и PR 286 (каталог `.harness/` через git без потолков символов).

## Как проверить

Тесты сборки постановки: каждая секция источника присутствует в выходе.

## Уроки

Потери контекста на стыке «цикл → исполнитель» невидимы без теста на присутствие каждой
секции; позднее это вылилось в отдельный контракт каталога задачи.
