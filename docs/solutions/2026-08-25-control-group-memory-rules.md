# Контрольная выборка — каждая N-я задача без правил

## Ситуация

Отчёт о пользе слоя памяти не может ответить на свой первый вопрос — «слой не мешает?» —
пока правила подсыпаются всегда. Доля дошедших до PR сама по себе ничего не говорит:
агент, честно сообщивший «работа уже сделана», PR не открывает и правильно делает.

## Причина

Нет второй выборки для сравнения; обвиняет только разница.

## Решение

`MEMORY_CONTROL_MOD=N`: каждая N-я задача идёт без запроса правил вовсе (не «запросили
и выбросили» — иначе «без правил» держалось бы на честном слове, закрыто тестом).
Деление детерминированное по номеру задачи: повтор той же задачи попадает в ту же выборку.
Умолчание — контроля нет: половина прогонов без опыта организации — цена проверки, а не
образ жизни. Опечатка в переменной выключает разделение, а не правила. Признак контроля
едет явно, а не выводится из пустого перечня правил: «не дали нарочно» и «не досталось,
слой лежал» — разные вещи; смешивание подмешивало бы брак в контрольную выборку.

## Как проверить

Тесты: одна и та же задача всегда в одной выборке; при контроле запроса правил нет.

## Уроки

Эффект обучения измеряется разницей с контрольной группой; «не просили» и «не получили» —
разные состояния, их маркируют явно.
