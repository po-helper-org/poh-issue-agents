# Агент разработки — в отдельном контейнере, не в воркере

## Ситуация

Полный цикл «без рук» не проходил ни разу: `DEVELOP_AUTOSTART` снимал только вторую
парковку, первая (ожидание решения об аналитике) оставалась. Живые прогоны нашли ещё три
дефекта: follow-up-задачи, создаваемые самим контуром, убивались предфильтром ботов
раньше, чем кто-либо смотрел на провенанс; собственная метка `run:analyze` запускала
второй прогон — на стенде вышло три аналитики подряд; приоритет считался без классификации.

## Причина

Агент разработки исполняет код чужого репозитория: внутри воркера это выполнение
произвольного кода рядом с GitHub-токеном и ключом модели.

## Решение

`DEVELOP_MODE=local` (умолчание): прогон одноразовым контейнером на своём сервере —
внутрь уходят только ключ и адрес модели; коммит, пуш и PR делает воркер. Образ агента —
свой Dockerfile (непривилегированный пользователь). `RESEARCH_AUTOSTART` снимает первую
парковку; тумблеры раздельные. Провенанс сильнее фильтра ботов: follow-up контура
не отбрасывается. Своя метка исхода не заводит второй прогон.

## Как проверить

Живой прогон с обоими автостартами: Issue проходит от триажа до PR без ручных меток;
в Temporal один прогон анализа на задачу.

## Уроки

Исполнение чужого кода изолируют контейнером; провенанс проверяют до фильтра ботов;
тумблеры этапов раздельные — «пусть сам исследует, а код запущу руками» — рабочий режим.
