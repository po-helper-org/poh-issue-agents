# Внешние агенты докладывают в цикл — HTTP-эндпоинт вместо общего Temporal

## Ситуация

Как только работа уходила в PR, трассировка Issue обрывалась: цикл запускал агента
разработки и больше не получал ни одного факта — «PR открыт», «ревью запросило
переделать», «CI упал». Соседние сервисы про Temporal этого контура не знают.

## Причина

Общая шина не нужна: нужен узкий контракт «событие агента → факт в жизни Issue», без
общего кода и деплоя.

## Решение

`POST /agent-event` с подписью (`X-Agent-Signature-256`, отдельный секрет, fail-closed):
типизированный конверт в `shared/agent_events.py`, корреляция `root_issue` → `Closes #N` →
конвенция ветки; неоднозначность не разрешается догадкой. Идемпотентный приём;
событие-сирота не теряется — воркфлоу `OrphanAgentEvent`. Открытый вопрос «один кластер
Temporal или несколько» закрыт в пользу HTTP: втягивание соседа в SDK и сетевой доступ
к кластеру — ровно та связность, от которой уходили.

## Как проверить

Тесты эндпоинта (подпись, идемпотентность, сироты); события внешних агентов двигают
фазы цикла.

## Уроки

Между сервисами — контракт событий по HTTP с подписью, а не общий оркестратор; сироту
сохраняют, а не выбрасывают: завтра корреляция появится.
