# Токен клонирования утекал в историю Temporal через текст исключения

## Ситуация

`/analyze` клонирует целевой репозиторий для изучения. Ревью ветки нашло: токен
клонирования попадает в event history Temporal и в логи.

## Причина

Ошибки subprocess (`CalledProcessError`, `TimeoutExpired`) несут argv команды в тексте —
токен передавался аргументом `git clone` и всплывал целиком при любом сбое команды.
Финальное ревью всей ветки добавило второе: `heartbeat_timeout=300 с` при стадиях до
900 с — реальный прогон падал бы через ~5 минут.

## Решение

Токен передаётся через git `credential.helper` в окружении, не в argv. Таймаут сердца
поднят до длительности стадии.

## Как проверить

В истории Temporal и логах воркера нет токена; стадия длиннее пяти минут переживает
heartbeat-окно.

## Уроки

Секрет в argv всплывает в трейсбеке subprocess — секреты ходят через env и хелперы;
длинной активности нужны сердцебиение и запас по таймауту.
