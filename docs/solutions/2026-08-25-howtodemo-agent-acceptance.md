# Приёмка по сценарию HowToDemo — отдельный агент-модуль

## Ситуация

Правило «нет HowToDemo — нет критерия готово» объявлено границей MVP в трёх документах,
но не подкреплено ни строкой исполняемого кода: ни один читатель контура сценарий не видел.

## Причина

Сценарий приёмки жил в теле Issue, а конвейеры читали тело без раздела приёмки.

## Решение

Агент-приёмщик отдельным пакетом на своей очереди Temporal (держит стенд и модель
десятками минут — цикл фаз не должен стоять за ней). Фиксирует сценарий, автономно проходит
его после доделки, докладывает «что готово / что не соответствует» с уликами. Автостарт
при входе в фазу PR отдельным прогоном без ожидания результата; идентификатор общий
с ручной командой — второй прогон по той же задаче невозможен по построению. Автостарт
выключен по умолчанию: поднимает контейнер на хосте и зовёт модель, включать молча на всех
репозиториях — эксперимент на чужих задачах. Флаг читается активностью, не воркфлоу —
правка переменной не ломает идущий прогон.

## Как проверить

Команда и автостарт: комментарий приёмщика с вердиктом и метки `demo:*`.

## Уроки

Правило, не подкреплённое исполняемой проверкой, — декларация; дорогая проверка живёт
отдельным прогоном и не блокирует цикл фаз.
