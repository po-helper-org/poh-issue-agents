Прототип · карта «Коробка БФТ v1» · тикет #346

BluePrint-карта инициативы: три формы

Кейс обезличенный: «Выгрузка заказов в CSV для бухгалтерии». В каждом варианте одни и те же данные, разная только форма страницы. Выберите форму — или возьмите куски из нескольких.

Рекомендация

Матрицу ответственности не придумывать. Готовая «матрица исполнения» уже есть в навыке /bft-matrix (poh-bft-writer): строки EX-NN, у каждой строки поставщик и проверяющий из другой команды, критерий «да/нет» с доказательством, покрытие ФТ, гейт 23. Формат вы утвердили 2026-10-15. Коробке остаётся собирать её как документ пакета kind: raci и проверять гейтом 23. Вкладка «Матрица» внизу показывает её форму.

Для BluePrint рекомендую вариант C («Было → стало по шагам»). Он читается с телефона, каждый шаг сразу ведёт к ФТ и к строке матрицы, а Confluence рисует его обычной таблицей. Вариант A точнее следует методологии, но он широкий и полезен только при большом числе слоёв; B хорош на старте, когда ещё нет ФТ.

Вариант C · рекомендуемый
