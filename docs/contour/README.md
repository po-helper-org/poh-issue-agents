# Контур производства v1: архив документов

Документы замороженных репозиториев контура «issue → разработка → PR → релиз».
Решения владельца 2026-10-09 (ADR-20/25/26) и 2026-10-16 (карта #344 «Коробка БФТ v1») вырезали из сборки контура
разработку (OpenHands), FNR-анализ кода, оценку, релиз и консолидацию — см. `docs/BFT-HARNESS.md`, раздел «Вне объёма».
Живая часть — «Коробка БФТ» в этом репозитории. Здесь сохранены дизайн и измерения, которые ещё могут пригодиться;
код замороженных репо остаётся в их истории (после переноса репо архивируются, не удаляются).

Состояние кода контура целиком на момент вырезки — тег **`contour-v1`** в этом репозитории.

- Файлы скопированы как есть. Относительные ссылки внутри них могут вести в несуществующие места старых репозиториев.
  В планах `security-agent/plans` локальный путь автора заменён на `~/`.
- Сообщения о стадиях и ADR, на которые ссылаются документы, — в `docs/DECISIONS.md` этого репозитория.
